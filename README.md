# Avaliação com Estrelas ⭐

Componente reutilizável em HTML/CSS/JS para avaliação de usuários por
estrelas (1 a 5), estilo "rate this product/experience".

![Preview](https://github.com/MasterySuporte/Avalia-o-de-Usuarios/assets/84245534/43cc3fa3-5c49-48fd-982f-7dd12cb03c8e)

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como rodar

Basta abrir `index.html` no navegador.
